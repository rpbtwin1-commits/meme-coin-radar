# Multi-Asset Radar V5 + Early Gems

Preserves V4's diversified paper portfolio and adds an Early Gems scanner.

Early Gems scores very-new Solana tokens using age, market cap, liquidity, volume, buy/sell flow, short-term momentum, public Solana token-account concentration, social/link presence, paid boost flags, and improvement between scans.

It does NOT auto-buy Early Gems. Optional `BIRDEYE_API_KEY` enables the Birdeye fresh-listing feed; zero-key mode still works with DEX Screener discovery.

A high score is a screening signal, not a guarantee of profit or future market cap.
